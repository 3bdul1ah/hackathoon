HOW TO LOG IN (on the 'Get help' tab):
  1. Type the Emirates ID below into the 'Emirates ID' box.
  2. Type the registered email address from the profile block below.
  3. Click 'Send email OTP'. A real Supabase email is sent when the project
     is configured; otherwise a demo code appears on screen.
  4. Type that code into the email OTP box.
  5. Click 'Verify identity', then type your issue in one box.
